879. What does this safety sign indicate?

  1. ①This is an area with busy bicycle traffic.
  2. ②This is a bicycle crossing.
  3. ③This is a bicycle parking space.
  4. ④This is a bicycle-only trail.
Show answer

Answer
① This is an area with busy bicycle traffic.

Reference
Appendix 6 of the Enforcement Rules of the Road Traffic Act. 134. Bicycle sign Notifies that there is a place where there is a lot of bicycle traffic.

Reference text is a machine translation for study.

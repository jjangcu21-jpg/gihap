391. Which of the following are TWO correct statements about the lines that separate lanes?

  1. ①Where a solid line and a broken line run parallel, you cannot change from the lane near the solid-line to the lane near the broken-line.
  2. ②Where a solid line and a broken line run parallel, you can change from the lane near the solid line to the lane near the broken line.
  3. ③Where a solid line and a broken line run parallel, you cannot change from the lane near the broken line to the lane near the solid line.
  4. ④Where a solid line and a broken line run parallel, you can change from the lane near the broken line to the lane near the solid line.
Show answer

Answer
① Where a solid line and a broken line run parallel, you cannot change from the lane near the solid-line to the lane near the broken-line.
④ Where a solid line and a broken line run parallel, you can change from the lane near the broken line to the lane near the solid line.

Reference
① Among the lanes that separate lanes, the solid lines are lines where lanes cannot be changed. ② The dotted line is a line where you can change lanes. ③ If a solid line and a dotted line run parallel, it is impossible to change lanes from the solid line to the dotted line. ④ If a solid line and a dotted line run parallel, you can change lanes from the dotted line to the solid line.

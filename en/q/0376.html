376. Which of the following is NOT correct regarding the variable speed limit section?

  1. ①It is an active system that changes the regulated speed in accordance with the situation.
  2. ②It uses an electric sign that can display different speeds by changing the numbers.
  3. ③When the maximum speed is set with a variable speed limit sign, it must be followed.
  4. ④When the maximum speed determined by the variable speed limit sign and the maximum speed of the safety sign show different values, the maximum speed indicated by the safety sign must be followed.
Show answer

Answer
④ When the maximum speed determined by the variable speed limit sign and the maximum speed of the safety sign show different values, the maximum speed indicated by the safety sign must be followed.

Reference
If the maximum speed is set by a variable speed limit sign in Article 19, Paragraph 1 of the Enforcement Rules of the Road Traffic Act, you must follow it. If the maximum speed set by a variable speed limit sign is different from the maximum speed set by other safety signs, you must follow the variable speed limit sign.

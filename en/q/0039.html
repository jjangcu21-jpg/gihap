39. Which of the following is NOT correct regarding charging stations of electric vehicles (EVs)?

  1. ①Common-use chargers refer to chargers installed in rest areas, large marts, and public offices.
  2. ②For the charging method of EVs, there are slow-charging methods using alternating current and fast-charging methods using direct current.
  3. ③Only pre-registered vehicles can use common-use chargers.
  4. ④If one possesses land or lot, one can install a personal charging facility.
Show answer

Answer
③ Only pre-registered vehicles can use common-use chargers.

Reference
Korea Electrical Code (KEC) 241.17, Electric Vehicle Power Supply Installations: Public chargers can be used by any driver who owns an electric vehicle.

Reference text is a machine translation for study.

安全标志题 · 2分

871. 关于安全标志的设置地点，下列哪项不正确？

  1. ①A标志应设置在可能有侧风危险的地点前50米至200米的道路右侧。
  2. ②B标志应设置在隧道入口前50米至200米的道路右侧。
  3. ③C标志应设置在危险区域前50米至200米的道路右侧。
  4. ④D标志应设置在公共停车场入口前50米至200米的道路右侧。 A B C D
查看答案

答案
④ D标志应设置在公共停车场入口前50米至200米的道路右侧。 A B C D

依据
安全标志为警示标志，其设置规则及位置详见道路交通法施行细则【附录6】。 A 标志安装在有侧风风险的地点前 50 至 200 米处的道路右侧（注意标志 137 号）。 B标志安装在隧道入口前50至200米处的道路右侧（警告标志138号）。 C 标志安装在危险区域前 50 至 200 米处的道路右侧（警告标志 140 号）。 D 标志安装在道路右侧、常拥堵路段前 50 至 200 米处（注意标志 141 号）。
